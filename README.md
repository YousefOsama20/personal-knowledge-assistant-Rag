
### 1. Create Your Environment

This project requires **Python 3.11+**. Create and activate a Python virtual environment:

#### On Windows:

```bash
python -m venv Agents
Agents\Scripts\activate
```

#### On macOS/Linux:

```bash
python3 -m venv venv
# 1. Make sure you are in the first-agent folder
cd /home/yoyo7/AI_Agent/personal-knowledge-assistant-Rag

# 2. Activate the virtual environment
source .venv/bin/activate

# 3. Run the script
python3 Agent_files/GEMINI.py

```# personal-knowledge-assistant-Rag
